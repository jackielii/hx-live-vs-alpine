Open state is a `data-open` attribute on the wrapper, the same place Alpine keeps `open` in its `x-data`. hx-live's `data.*` resolves to the closest ancestor carrying that attribute, so both the button and the panel read the wrapper's value without any extra plumbing.

Alpine attaches its `.outside` modifier to the contents div and gets away with it because Alpine's outside handler ignores elements that are currently hidden, so the toggle button's own click never counts as an outside click. htmx's `from:outside` is purely geometric: the toggle button sits outside the contents div, so putting the listener there would close the panel on the same click that opened it. Attaching it to the component root instead makes every click inside the component "inside," which is what the reader actually means.
