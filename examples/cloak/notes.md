Alpine removes `x-cloak` when it initialises an element, so a `[x-cloak] { display: none }` rule hides markup until then. hx-live has no cloak directive, but a binding can remove any attribute: binding `null` to a plain attribute drops it, so `:hx-cloak="null"` clears the marker in the same evaluation pass that applies `:hidden`, and the same CSS trick works.
